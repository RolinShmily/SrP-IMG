# 书写约定

四套语言各守一条边界：React 只做展示、Python 只做构建期生成、Worker JS 只做请求处理。谁生成什么、谁不能 import 谁，见 [../architecture/layers.md](../architecture/layers.md)；本篇只讲"写的时候长什么样"。

## 通用项

| 约定 | 说明 | 出处 |
| --- | --- | --- |
| 行尾统一 LF | 仓库与工作区都归一为 LF，Windows 检出与 Linux CI 逐字节一致 | `.gitattributes`（`* text=auto eol=lf`） |
| 缩进 | 默认 2 空格；`*.py`、`worker/*.js`、`functions/*.js` 为 4 空格 | `.editorconfig` |
| 文件结尾 | 必须有一个换行；非 Markdown 去掉尾随空格 | `.editorconfig` |
| 生成物不手改 | `worker/targets.js`、`worker/slot_formats.js`、`assets/generated/counts.json` 由 `python -m pipeline` 重写 | `pipeline/__init__.py`、`.github/workflows/ci.yml` |
| 注释写"为什么" | 解释被否掉的方案、顺序约束、平台差异；不复述代码在做什么 | 代码注释现状（如 `vite.config.ts`、`worker/index.js`） |
| 生成文件带警示头 | 生成的模块首行固定为 `// Generated by \`python -m pipeline\`. Do not edit.` | `tests/pipeline/test_pipeline.py` |

## TypeScript / React（`src/`）

| 约定 | 做法 | 出处 |
| --- | --- | --- |
| 组件形态 | 全部函数组件：`src/components/*` 用具名导出（`export function Footer()`），`src/pages/*` 用默认导出（`export default function HomePage()`） | `src/components/footer.tsx`、`src/pages/home.tsx` |
| 别名 | 一律用 `@/` 而不是相对路径穿透目录；`@` → `./src` | `vite.config.ts`、`tsconfig.json`（`paths`） |
| 类型检查 | `strict: true`、`noEmit: true`、`jsx: react-jsx`；`npm run typecheck` 是唯一类型门禁 | `tsconfig.json`、`package.json` |
| 不用 `"use client"` | 纯客户端 SPA，没有 RSC 边界；仓库内无该指令 | `src/main.tsx`（`createRoot` 挂载） |
| 类名合并 | 条件类名走 `cn()`（`clsx` + `tailwind-merge`），不用手写字符串拼接 | `src/lib/utils.ts`、`components.json` |
| Tailwind 类顺序 | 同一元素内按"尺寸/间距 → 布局 → 文字/字体 → 颜色 → 交互与过渡 → 状态与焦点"分组，就近写变体前缀 | `src/components/api-panel.tsx` |
| 可达性 | 控件必须有 `aria-*`（`aria-expanded` / `aria-controls` / `aria-pressed` / `aria-label`）；装饰图标 `aria-hidden="true"`；动态文本用 `role="status"` + `aria-live` | `src/components/api-panel.tsx` |
| 焦点可见 | 可点区域统一 `focus-visible:outline-2 focus-visible:outline-primary`，不删除默认轮廓而不给替代 | `src/components/api-panel.tsx` |
| 文案 | 中文/英文都进 `src/lib/*-translations.ts`，不硬编码在 JSX 里 | `src/lib/i18n.tsx`、`src/lib/api-translations.ts` |

样式 token 与字体规范不在这里重复，见 [../design/tokens.md](../design/tokens.md)；双语与键盘细节见 [../design/i18n-accessibility.md](../design/i18n-accessibility.md)。

## Python（`pipeline/`、`tests/*.py`）

| 约定 | 做法 | 出处 |
| --- | --- | --- |
| 只用标准库 | 不引入第三方包；`argparse` / `dataclasses` / `pathlib` / `hashlib` / `struct` 已经够用 | `pipeline/config.py`、`tests/pipeline/test_pipeline.py` 的 import 段 |
| 缩进 4 空格 | 与 `.editorconfig` 的 `[*.py]` 段一致 | `.editorconfig` |
| 路径用 `pathlib` | `Path` 组合代替字符串拼接；扫描/写出都传 `Path` | `pipeline/config.py`、`pipeline/pool.py` |
| 写出固定 `newline='\n'` | 避免 Windows 上把 LF 写成 CRLF，破坏与 CI 的逐字节对比 | `pipeline/manifest.py`、`pipeline/worker_targets.py` |
| 类型标注 | 公开函数签名标注参数与返回值（`List` / `Optional` / `Path`），`from __future__` 不需要 | `pipeline/cli.py`、`pipeline/config.py` |
| docstring 写"为什么" | 模块级说明顺序为何是契约、为何空扫描零写入；不只写"做什么" | `pipeline/cli.py`、`pipeline/manifest.py` |
| 参数解析集中 | CLI 参数只在 `Config.from_args()` 定义，默认值以常量出现在模块顶部 | `pipeline/config.py` |
| 相对 cwd 的默认路径 | 输出路径相对当前目录（`assets/original`、`assets/generated`、`worker/targets.js`）；catalog 与 schema 锚定包位置 | `pipeline/config.py` 注释 |

`--access-policy` 之类的旧参数已经移除，再用会以退出码 2 结束（`pipeline/config.py`、`tests/test_access_policy.py`）。

## Worker JS（`worker/`、`functions/`）

| 约定 | 做法 | 出处 |
| --- | --- | --- |
| 纯 ESM | `import` / `export`，无 CommonJS、无构建步骤；`package.json` 的 `"type": "module"` | `package.json`、`worker/index.js` |
| 缩进 4 空格 | `[worker/*.js]` 与 `[functions/*.js]` 单独规定，别用格式化工具改成 2 空格 | `.editorconfig` |
| 不用框架 | 只有 `fetch(request, env)` 与确切的 `Response`/`Request`/`Headers` 标准对象 | `worker/index.js` |
| 责任切分 | 请求策略全在 `worker/policy.js`；`worker/index.js` 只做路由与 `Content-Type` 纠正；Pages 适配在 `worker/pages.js` | `worker/index.js` 头注释 |
| 改头先复制 | `const headers = new Headers(response.headers)` 后再 `set`/`delete`，不改原对象 | `worker/index.js`、`worker/policy.js` |
| 单引号 + 分号 | 运行时源码统一单引号、语句结尾带分号 | `worker/policy.js` |
| 不写死部署值 | 允许名单只从 `env` 读；源码里不出现 `ACCESS_POLICY`、域名等常量 | `tests/test_access_policy.py` |

## ESLint 配置

| 项 | 内容 | 出处 |
| --- | --- | --- |
| 位置 | `eslint.config.mjs`（flat config），`npm run lint` = `eslint .` | `eslint.config.mjs`、`package.json` |
| 忽略 | `dist/**`、`build/**`、`.wrangler/**`、`node_modules/**`、`assets/**`、`worker/targets.js`、`worker/slot_formats.js` | `eslint.config.mjs`（`globalIgnores`） |
| JS 文件 | `js.configs.recommended` + Node 全局变量 | `eslint.config.mjs` |
| TS/TSX | `typescript-eslint` recommended + 浏览器与 Node 全局 | `eslint.config.mjs` |
| Hooks | `react-hooks/rules-of-hooks` 为 error，`exhaustive-deps` 为 warn | `eslint.config.mjs` |
| 未使用变量 | warn，但 `^_` 前缀的参数/变量/捕获异常豁免（保留签名用） | `eslint.config.mjs` |

注意 `ESLint` 不检查 `assets/**` 与两个生成的数据模块：它们是构建输入或生成物，lint 只会与生成器互相打架（`eslint.config.mjs` 注释）。
